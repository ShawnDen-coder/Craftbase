# 设计基础 v0.1

适用于个人工具、内容管理与桌面密度 Web 应用。营销视觉与品牌插画不在首期范围。规则是 Craftbase 的 Web 设计判断；Apple 的原生 API 或参数不直接等同于 CSS。

| 规则         | 用途与参数                                           | 状态变化                    | 边界与示例                                               |
| ------------ | ---------------------------------------------------- | --------------------------- | -------------------------------------------------------- |
| 语义优先     | surface / text / action / selection / status / focus | appearance 只改颜色与材质   | 业务使用 surface.panel，不直接引用某个灰色               |
| 密度独立     | comfortable 36px 控件、compact 28px 控件             | density 只改尺寸与间距      | 触屏需扩大点击区，不能将 28px 作为触屏默认               |
| 文字层级     | 12px 说明、14px 正文、20px 标题，正文行高 1.5        | 选中项 600 字重             | 中文长标题允许换行，检查字重变化后的布局                 |
| 间距尺度     | 4 / 8 / 12 / 16 / 24 / 32px                          | 不随 appearance 变化        | 组内间距小于组间距离                                     |
| 圆角关系     | control 8px、panel 16px                              | 与容器内边距共同评估        | 同心形状内角可参考 max(0, 外角−内边距)，并非通用强制公式 |
| 材质表达层级 | overlay 实色回退＋可选玻璃＋边界＋投影               | 减少透明度、高对比度下实色  | 只用于导航/控件的功能层，不给内容卡片加玻璃；不嵌套玻璃  |
| 焦点独立可见 | 2px 轮廓、3px 偏移                                   | focus-visible 与 hover 分开 | outline 不得裁切；不能只靠选中背景表示焦点               |
| 动效服务反馈 | 120 / 180ms                                          | reduced 为 0ms              | 状态机不能依赖 transitionend 才完成关键操作              |

## 组件实现验收

- 覆盖规格声明的所有状态、两种 appearance 与两种 density。
- 键盘独立完成流程；弹层检查初始焦点、焦点约束、关闭与恢复。
- 验证中文输入法、长文本、200% 缩放、320px 窄屏，以及触屏目标大小。
- 默认正文目标对比度至少 4.5:1；焦点和必要控件边界至少 3:1。透明材质必须针对真实背景另测。
- 检查 loading、empty、error 和重试；错误不得丢失用户输入。
- 验证 reduced motion、透明度回退、forced colors；不得把自动化颜色检查当成完整无障碍认证。

组件实现前选择并核查可访问交互基础库；Menu/Dialog 不从零随意拼装焦点行为。React/Vue 共享规格，分别保留自然的事件、插槽与状态接口。

macOS 的具体转译、来源和待验收项见 [macOS 落地契约](macos.md)。
