## 保留的 Web 取舍

- 普通卡片保持实色，不把整个网站玻璃化。原稿 Form 也采用实色内容区。
- 开关开启轨道使用原稿蓝色；含文字的按钮和分段选择继续使用既有可读操作色，未直接照搬亮蓝加白字。
- 关闭轨道和滑块保留更清楚的边界；网页密度不等于原稿 native size。
- 用户选择的 JetBrains Mono / Sarasa Term SC 属于网站字体选项，并非原稿 SF Pro 的复刻。
- CSS 玻璃仍是 Web 近似：高光、透色和阴影可映射，无法据此宣称与原生动态折射完全一致。复杂背景下的玻璃适应是后续值得专项优化的部分。

## 深色描边复查

用户反馈后重新读取 `4336:13804`（Dark / Idle）和 `4336:13799`（Dark / Focused）。原稿空闲输入表面为 `#1e1e1e`、1px 白色 4% 描边；聚焦另有蓝色环。此前将 `border.control #9296a3` 用于普通边界，导致亮灰线过强，属于映射错误。

现增加 `field.fill` 与 `field.border`，深色输入、搜索、文本域按原稿映射，下拉框沿用同一表面语言。亮色保持现状；清晰焦点环保留，高对比模式恢复强边界。浏览器已检查实际计算值、聚焦与高对比模式，并复看修正截图。
