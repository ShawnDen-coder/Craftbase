# 桌面样式参考调整

2026-10-23，按用户最新定位：只维护 macOS 桌面网页，网站以材质与样式规则为主，组件作为切换外观时的观察样例。

## 内容与排版

- 移除网站接入指南、用法／源码标签、属性 API 表和源码查看器。保留单项外观观察入口。
- 新增样式展板：固定外观控制，六组独立高度样例，包含 Radix 开关、分段页签、滑块、复选框及现有菜单、对话框等交互。
- 文档每页保留一个主标题；统一章节间距、阅读宽度、列表样式与控制栏。文字角色改为完整宽度的三列对照，空间规则独立成节。
- 首页以材质和基础规则为先，README 与路线同步新定位。移除手机专属断点和首页入场动画，保留交互反馈及减少动态偏好。

## 验证

`pnpm verify` 通过：Biome、生成物同步、6 项基础测试、TypeScript 与 Vite 构建。

Playwright 检查 1024、1440、1920px 的首页、展板及全部规则页，没有横向溢出或运行错误；每页一个主标题。展板明暗外观、开关、滑块键盘操作、页签、复选框、搜索空态和列表选择通过。

品味 skill 使用桌面宽度检查与三轮看图调整。最终展板检查为 0 FAIL / 1 WARN。按 macOS 材质要求保留玻璃样片的渐变观察背景与投影，显式允许 gradient、heavy-shadow；其余卡片不使用投影。剩余提示为玻璃样片到菜单之间约50px的视觉间距，保留以免菜单与材质阴影挤在一起。

截图与检查报告位于工作区 `artifacts/browser-check/` 和 `.taste-skill/`，不进入网站构建。浏览器仿真不等同于完整读屏认证；玻璃仍是 Web 近似。
