## 展示站落地复核

- shadcn / Radix 组件已接入，主题由 Craftbase Token 映射。Button 默认不提交表单，loading 保留名称与宽度并阻断重复操作；danger 文字配对已进入自动对比度测试。
- small 与 density 已分开。浏览器实测 macOS 舒适：默认 36px、小尺寸 28px；Neutral 紧凑：默认 28px、小尺寸约 24px。窗口活动与按压使用不同状态；内容／玻璃功能层分开展示。
- 材质区可切换亮、暗、复杂背景，显式减少透明度后 computed style 为实色且 backdrop-filter=none。未把此结果扩大为所有系统偏好都已验证。
- 列表详情失败后保留草稿，关闭模拟失败可重试成功。未保存切换默认聚焦继续编辑；取消保留草稿并返回输入框，明确放弃才切换。
- 菜单打开编辑弹层后，关闭焦点回到菜单触发按钮；普通 Dialog 表单错误保持打开，保存后恢复触发器。
- 390px 列表详情单区呈现，页面 scrollWidth=390 与 viewport=390 一致。桌面改为不透明 sticky 工具栏，导航选中使用独立 aria-current，避免以 hover 代替选中。

未关闭的验证项：全部系统辅助功能、320px／200% 缩放、URL 无效记录与恢复、长文本、完整键盘边界和实际项目复用。完整色阶不在当前语义色卡中冒充已完成；Vue 和 Registry 发布仍是后续阶段。

URL 验收补充：筛选与选中记录可从链接恢复；返回列表保留筛选；空结果可清除；失效记录说明在窄屏也可见。320px 页面无横向溢出。首次带锚点进入时增加渲染后定位，浏览器确认已到目标段落。浏览器工具暂不支持系统媒体偏好仿真，缩放快捷键未生效，因此 200% 与系统偏好不记为通过。

键盘复核发现并修复 Radix 默认 Tab 拦截与本项目 Menu 规格的差异。现在关闭菜单后按页面顺序转移焦点，浏览器实测 Tab 到“编辑设计基础”，Shift+Tab 到“设计基础名称”。源码新增受控／非受控 open 适配和触发器 ref，保留外部 onOpenChange/onCloseAutoFocus。

## Playwright 补充验收 · 2026-10-22

用户授权后，在独立 Chromium 测试配置中使用 Playwright 1.64.1 完成以下检查；工具安装在临时目录，未增加项目依赖。
- 系统媒体仿真：逐项确认 matchMedia 命中。减少透明度使玻璃背景实色且 backdrop-filter 为 none；增加对比度同时令边框与正文颜色一致；强制颜色使用系统色、移除模糊与阴影；减少动态令基础 motion-fast Token 为 0ms。覆盖 macOS 浅色及 Neutral 深色的代表场景，不等于完整辅助技术认证。
- 修复展示站 HTML 缺失 cb-root 标记，保证基础偏好配方实际作用于根节点。此前展示站自身的减少动态规则存在，但底层动效 Token 未随系统偏好归零。
- macOS／Neutral × 浅色／深色 × 舒适／紧凑共 8 组切换均无页面横向溢出。这是切换和布局冒烟检查，不代表全部组件状态矩阵已验收。
- 通过隔离测试扩展调用 chrome.tabs.setZoom(2)，并读取 getZoom=2；1440px 视口变为 720 CSS px、devicePixelRatio 从 1 变为 2、scrollWidth=720。Neutral 深色紧凑下编辑弹窗边界为 x=136、y=146、width=448、height=208，保持在 720×500 CSS px 可视区域内；中心命中名称输入框。页面无未捕获 JavaScript 错误。
- 缩放截图捕获存在异常：普通截图为空白，全页截图有裁切，因此只将上述缩放值、DOM 布局和命中检查记为通过，不将截图记为视觉验收通过。200% 实际视觉复核、读屏器、长文本及真实项目复用仍待完成。

修复后 pnpm verify 通过：Biome 45 个文件、生成物同步、3 项测试、TypeScript 检查与 Vite 生产构建。
