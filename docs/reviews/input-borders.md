# 输入框与下拉框边线复核

2026-10-23，通过 Figma get_design_context 与截图核对。
- 浅色输入框 Idle：`479:5481`，白色填充、1px / 8% 黑色边缘。此前误用了不透明 `#737680` 控件边界。
- 深色输入框 Idle：`4336:13804`，`#1e1e1e` 填充、1px / 4% 白色边缘。
- 浅色 Focused：`479:5478`，3.5px / 50% 蓝色焦点环，贴合外沿。移除通用 Input 的双重焦点样式，保留错误与强制色彩状态。
- Pop-Up Button：`218:4483`，8% 黑色填充，无输入框式描边。网站 select 使用已有 secondary fill；仍保留浏览器原生选择交互和箭头，未宣称与原生 macOS 完全一致。

网站通过 CSS border 近似原稿浅色输入框的外扩细边；参考样片参数不变。增强对比时恢复强边界。

验证：pnpm verify；Playwright 检查两种外观的实际边线、菜单与弹窗、1024/1440/1920 宽度。人工复核浅色、深色及弹窗焦点截图。
