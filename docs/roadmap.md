# 推进计划

## 当前定位

Craftbase 用于长期沉淀个人基础设计。以颜色、文字、空间、尺寸、状态、层级和材质规则为核心；展示站和真实组件用于观察、验证与复用这些规则。macOS 是当前研究参考之一，不限定项目方向。

## 当前已有

- [x] 框架无关的基础尺度、语义色彩和两档密度 Token。
- [x] 浅色、深色与跟随系统的展示设置。
- [x] 色彩、文字、状态和材质观察页。
- [x] macOS 材质与外观参考证据，独立于基础语义 Token。
- [x] shadcn/ui 第一轮适配：按钮、输入框、菜单、弹窗。
- [x] 桌面展示与浏览器检查；组件样例保留交互。

## 后续优化

- 根据自己的实际界面提炼设计原则，明确哪些是长期基础规则、哪些只是某次参考研究。
- 扩充 shadcn 适配与状态覆盖，根据实际需求验证 Nova 等变体。
- 根据业务需要增加其他组件库适配，共用基础设计源。
- 持续补充参考来源、选择理由、真实场景和可访问性验证。

## 范围边界

项目不以发布完整组件库为目标。现有 React 样例服务于设计验证；MUI、Vue、可安装 Registry 和其他适配尚未实现，不作为已支持能力展示。

此前仅维护 macOS 桌面参考站的描述属于历史阶段，已由当前个人基础设计定位取代。
